# ApkShellext2 4.1.0

A small feature release: the context menu can put the selected packages' values on the
clipboard.

## Highlights

- **Copy submenu.** The context menu gains a **Copy info** submenu with **Copy File Path**,
  **Copy App Name**, **Copy Package Name** and **Copy Version**. It works on a multi-selection:
  one line per file, in the order the files were selected, CRLF-separated with no trailing line
  break. The version line follows the CSV columns, so a package with a revision reads
  `1.2.3 (42)`. An item is offered only when at least one selected file can fill it, and the
  submenu itself appears only when at least one item is available — a selection the extension
  cannot parse still offers **Copy File Path**. The values come from the same readers that
  supply the info tip, so `.ipa`, `.appx`, `.appxbundle` and `.aab` selections work as well.
  The write happens on the menu's STA UI thread and a failure is logged rather than raised into
  Explorer.

- **Info tip facts.** The info tip can now show the min SDK level, the target SDK level and the
  packer name next to the existing version, package and size rows. The default pattern keeps
  `Min SDK:`, `Target SDK:` and `Packer:` for a package that carries those facts and drops a row
  whole when its fact is missing, so an `.ipa` or `.appx` tip does not show the Android SDK or
  packer labels and still keeps its size row. The min/target SDK tokens are also offered by the
  rename-pattern list.

## Sizes

The release adds text-generation code and no images: `ApkShellext2.dll` grows from
914,944 B to 923,648 B (+8,704 B), the 7z package is 703,691 B against 700,725 B, and the
deployment tree is 2,138,298 B in 28 files.
