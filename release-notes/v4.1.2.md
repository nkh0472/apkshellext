# ApkShellext2 4.1.2

A settings fix and a documentation rewrite. Nothing about how packages are read changes.

## Highlights

- **A feature switch is off only when the value really says so.** Every switch compared the
  stored text to `"True"`, so a value written as a DWORD (`0`/`1`, which is what the registry
  editor and older builds produce) or in another spelling (`yes`, `on`, `1`) read as off:
  overlay badges, thumbnail stretching, adaptive icons, the store entries and the debug log
  could all silently turn themselves off. All 39 call sites now go through
  `Utility.GetSettingBool`, which accepts the text and numeric forms, treats an empty value as
  off, and keeps the caller's default for a value it cannot read.

- **The error log switch reads the same way.** `DebugLog` decides whether the extension logs
  anything at all, so it is checked before the first line is written instead of parsing the raw
  value itself.

- **19 new tests pin the accepted forms**: `true/yes/on/1`, `false/no/off/0`, whitespace, an
  empty string, an unrecognised value keeping the fallback, and a DWORD `1`/`0` read back
  through the real settings key.

- **The README features section is now two tables** — what you get in Explorer, and what it is
  built on — instead of a ten-bullet list with the important parts buried.

## Upgrade notes

- `update.bat` replaces the whole deployment folder; a manual update must copy the dll **and**
  the 19 language folders together, because a satellite assembly whose version does not match
  the main assembly makes the UI fall back to English.
- Settings written by older builds keep working: the numeric and text forms are both read the
  way their writer meant them, so no value has to be re-saved.

## Known issues

- Windows 11 22H2+ uses the modern `IExplorerCommand` menu; Windows 10 and *Show more options*
  use the classic one. Both keep the same entries in the same order.
- Thumbnails are offered for `.apk` only; an older thumbnail may be served from the Explorer
  cache until the cache is cleared.
- The extension ships unsigned; sign the package yourself if your policy requires it.
