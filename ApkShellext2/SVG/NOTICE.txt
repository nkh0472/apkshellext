This directory used to be a git submodule (vvvv/SVG). It is now kept in-tree
so the renderer can be trimmed locally without requiring a fork of upstream.
Only what the build consumes is vendored:

  Source\        the SVG library sources, glob-compiled into ApkShellext2.dll
  Generators\    the Roslyn source generator (Element metadata), referenced as
                 an analyzer by ApkShellext2.csproj
  license.txt    upstream license text

The upstream tests, docs, samples and .github tree are not vendored.

Local modifications are maintained in this tree; see
`git log -- ApkShellext2/SVG`. Do not copy upstream files over this tree
without re-reading that log first. Current local modifications:

  - removed the ExCSS dependency and the Svg.Css selector engine
    (Css\ExCssQuery.cs, Css\ExSvgElementOps.cs, Css\IExCssSelectorOps.cs);
    CSS stylesheets in a document, or a css argument to Create/Open, are
    accepted and ignored. The only SVG producer in this product
    (VectorDrawableToSvg) emits presentation attributes and never <style>
    or selectors, so rendering is unchanged;
  - replaced the inline `style` attribute parser with a small direct
    "name: value; name2: value2" parser (same AddStyle/InlineStyle path as
    before); full CSS syntax is intentionally not supported.
  - removed the unused rendering subtrees that the product's only SVG
    producer never exercises: Text\ (text and font rendering), Filter Effects\
    (every SvgFe* primitive), Extensibility\ (foreignObject) and the raster
    <image> element (Document Structure\SvgImage*). VectorDrawableToSvg emits
    paths, groups, gradients and clips only, so rendered output is unchanged.
    The ExternalType switches stay because ApkQuickReader sets them to None.

When updating from upstream, keep the in-tree path layout (the product csproj
globs SVG\Source\**\*.cs and project-references SVG\Generators\).
